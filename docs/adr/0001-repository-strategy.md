# ADR-0001: Repository Strategy

- **Status:** Accepted
- **Date:** 2026-10-08

## Context

The fork must remain independently maintainable while preserving attribution, legal boundaries, and long-term contributor operability.

## Decision

Maintain this project as an independent fork with:
- explicit ownership governance
- upstream-aware synchronization policy
- strict publication validation checks
- documented contributor/AI standards in `.github/copilot-instructions.md`

## Consequences

Positive:
- clear governance and accountability
- stable path for long-term maintenance

Trade-offs:
- additional process overhead for verification and documentation updates
